# وان هاوس — ريلز 3D

فيديو ريلز عمودي (1080×1920، 30 إطار/ث، 81 ثانية) لشركة One House: لقطة 3D واحدة متصلة لعمارة بتتبني قدامك، متزامنة كلمة بكلمة مع التعليق الصوتي المصري (ElevenLabs)، مع عناوين متحركة وكابشن وموسيقى ومؤثرات. معمول بـ [Remotion](https://www.remotion.dev/) و Three.js (React Three Fiber). المعلومات (الخدمات، وحدات الحمام، الأرقام) من موقع الشركة [onehouse-eg.web.app](https://onehouse-eg.web.app/).

النسخة المرندرة: [`renders/one-house-reel.mp4`](renders/one-house-reel.mp4) · السكريبت: [`SCRIPT.md`](SCRIPT.md)

## الفكرة

الفيديو بيبدأ بالعمارة **خلصانة** وقت المغرب، والكاميرا بتقرّب على «شقتك». مع «إيه اللي جوّه الحيطة؟» الحيطان بتشف زي الأشعة: الحديد بينوّر أحمر، والخرسانة أزرق، والكاميرا بتغطس تحت الأرض للقواعد. مع «تعالى أوريك» الزمن **بيرجع لورا** لحد ما الأرض تبقى فاضية، يظهر اللوجو، وبعدها العمارة بتتبني من الصفر، وكل مرحلة على الكلمة بتاعتها بالظبط:

حفر ← خرسانة نضيفة ← قواعد مسلحة ← أقفاص حديد الأعمدة ← مراجعة المهندس ← صب الأعمدة ← غابة القوايم والعروق تحت السقف ← ليزر الميزان ← صب السقف ← الأدوار بتطلع مع ونش برجي وعمّال ← حر الصيف وبرد الشتا ← فك الشدّة ← سباكة وكهربا وعزل ومحارة ورخام ودهانات ← العمارة كلها تتحول لتصميم 3D وترجع حقيقية ← دخول على حمام بوحدة بورديوم والمية بتخبط فيها ← لقطة من فوق للمدينة وأسطح مشاريع وان هاوس بتنوّر أحمر مع عدّاد +500 ← الليل، اللوجو، «احجز استشارتك المجانية».

## الملفات

- `src/world/` — العالم الـ 3D: العمارة ومراحلها (`Building.tsx`)، الموقع والمدينة والعمال (`Site.tsx`)، الحمام (`BathroomSet.tsx`)، الكاميرا والإضاءة (`World.tsx`)، الخامات (`materials.ts`).
- `src/cues.ts` — كل لحظة في الفيلم مربوطة بكلمة من التعليق (`cue("حفر")` …).
- `src/overlay/` — العناوين والكابشن واللوجو والعدّادات وكارت النهاية والمؤثرات الصوتية.
- `src/narration.ts` — نص التعليق كما اتسجل.

## الصوت والتوقيت

```console
python3 scripts/transcribe.py path/to/recording.mp3   # يظبط الصوت ويفرّغه بـ Whisper (faster-whisper)
python3 scripts/generate-audio.py                     # يطابق النص على التفريغ، ويكتب src/timeline.json، ويولّد الموسيقى والمؤثرات
```

الموسيقى والمؤثرات متولّدة بالكود (مفيش مشاكل حقوق)، وبتوطى أوتوماتيك وقت ما المعلّق بيتكلم علشان مفيش حرف يضيع.

## المعاينة والرندر

```console
npm i
npm run dev                                                   # Remotion Studio
npx remotion render OneHouseReel renders/one-house-reel.mp4   # الرندر بياخد حوالي ساعة على 4 أنوية (WebGL سوفتوير)
```

`remotion.config.ts` بيشغّل WebGL بـ `swangle` علشان الرندر يشتغل على أي جهاز من غير كارت شاشة.
