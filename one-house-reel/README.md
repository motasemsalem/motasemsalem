# وان هاوس — ريلز موشن جرافيك

فيديو ريلز عمودي (1080×1920، 30 إطار/ث، 94 ثانية) لشركة One House، بتعليق صوتي مصري وموسيقى ومؤثرات وكابشن متزامن كلمة بكلمة، معمول بـ [Remotion](https://www.remotion.dev/) من صور مواقع الشغل واللوجو.

النسخة المرندرة: [`renders/one-house-reel.mp4`](renders/one-house-reel.mp4)

## المشاهد

1. **الهوك** — «استنّى!» بضربة جليتش، مفتاح بيت على شكل اللوجو، مونتاج سريع مستخبي ورا زجاج مغبّش من صور المواقع («حكاية إنت ما شُفتهاش»)، قطاع في الأرض بيتحفر وعمارة بتطلع منه لحد ما المفتاح يقع.
2. **اللوجو** — ظهور اللوجو مع دروب الموسيقى، شرارات وحلقات هندسية ولمعة ضوء.
3. **الأساسات** — صورة الموقع + قطاع في القاعدة بيترسم (نضافة، قاعدة مسلحة، رقبة العمود).
4. **الأعمدة** — قفص حديد بيترسم وقايمة مراجعة.
5. **الشدّة الخشبية** — صورتين للشدّة مع تحديد القوايم والعروق وميزان مية بيظبط.
6. **دور ورا دور** — صور جوية، عدّاد أدوار، «فريقنا في الموقع»، في الحر وفي البرد.
7. **القيم** — خامات مضمونة · التزام بالمواعيد · شفافية.
8. **المراحل** — تصميم ← تنفيذ ← تشطيب ← تسليم، وموبايل عليه تحديثات من الموقع.
9. **الختام** — اللوجو الأصلي على أبيض، طوب بيتبني، وزرار «ابعتلنا رسالة دلوقتي».

## الصوت

- **التعليق الصوتي:** نصه في `src/narration.ts`، ومولَّد بـ ElevenLabs (صوت Brian، موديل `eleven_v3`) في `public/voiceover/` مع توقيت كل حرف (`.json`) للكابشن.
  كل مقطع اتراجع بتفريغه بـ Whisper (large-v3) ومقارنته بالنص؛ الجمل اللي فيها غلطة نطق اتغيرت صياغتها أو اتولدت بـ seed تاني (`seed` في `narration.ts`).
- **الموسيقى والمؤثرات:** متولّدة بالكود (`scripts/generate-audio.py`) — موسيقى 120 BPM الدروب بتاعها على اللوجو وأقسامها ماشية مع المشاهد، ومؤثرات (whoosh، impact، riser، شاكوش، شتر كاميرا، مفاتيح…). مفيش أي مشاكل حقوق.
- `scripts/generate-audio.py` كمان بيكتب `src/timeline.json` (طول كل مشهد من طول صوته + توقيت الكلمات)، فالفيديو والموسيقى بيقطعوا في نفس اللحظة.

لو عدلت النص:

```console
ELEVENLABS_API_KEY=sk_... NODE_USE_ENV_PROXY=1 node --experimental-strip-types scripts/generate-voiceover.ts --force <scene>
python3 scripts/generate-audio.py      # محتاج numpy و scipy و ffmpeg
```

## التعديل

- النصوص والحركة: `src/scenes/`
- المكونات المشتركة (كارت الصورة، الكول أوت، الكابشن، العمارة الأيزومتريك، المفتاح): `src/components/`
- الألوان والخطوط: `src/theme.ts`

```console
npm i
npm run dev                                   # Remotion Studio للمعاينة والتعديل
npx remotion render OneHouseReel renders/one-house-reel.mp4
```

الخطوط (Alexandria و IBM Plex Sans Arabic) موجودة في `public/fonts` برخصة SIL OFL. الصورتين الجويتين اتقصّ منهم الجزء اللي تحت اللي كان فيه علامة مولّد الصور.
