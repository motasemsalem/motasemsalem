# ريل: القبائل العربية في مصر

فيديو رأسي 1080×1920، 30fps، طوله ~4:13، بستايل «وثائقي ذهبي» على غرار الفيديو المرجعي:
خلفية بنّي غامق بنقش نجوم، خيط ذهبي بكرة نور بيربط المشاهد، صور أرشيفية في براويز ذهب،
كلمات مفتاحية بخط الرقعة، خرائط أقمار صناعية ذهبية بمسارات منوّرة، وترجمة كاريوكي.

## الملفات
| المسار | المحتوى |
|---|---|
| `inputs/` | الصوت والسكريبت والخطة، و`words.json` (توقيت كل كلمة في الصوت) |
| `assets/photos/` | صور مكتبة الكونجرس بعد القص وتوحيد اللون |
| `assets/map/` | موزاييك Sentinel-2 + حدود Natural Earth |
| `assets/music/` | موسيقى Kevin MacLeod (CC BY 4.0) |
| `assets/SOURCES.md` | **المصادر والتراخيص ونص النسبة المطلوب في الوصف** |
| `fonts/` | Aref Ruqaa وAmiri وCairo (OFL) |
| `build/` | كود الرندر |

## إعادة البناء
```bash
python3 build/align_words.py          # توقيت الكلمات (faster-whisper + مطابقة مع السكريبت)
python3 build/prep_photos.py          # تنزيل الصور الأصلية وقصها وتوحيد لونها
python3 build/fetch_map.py            # موزاييك الخرائط
python3 build/render_reel.py stills 2.6 89.2 150   # فريمات للمراجعة
python3 build/render_reel.py video                 # الفيديو الكامل + نسخة بدون موسيقى
```
الناتج في `build/out/`.

## إزاي الكود متقسم
- `reel_story.py` — الستوري بورد. كل لحظة مربوطة بكلمة بتتقال: `at("هَوّارة")` بترجع وقت نطقها.
- `reel_elements.py` — عناصر الكانفاس: براويز، نوافذ نجمة، ميداليات، كروت، عدّادات، قايمة القبائل.
- `reel_map.py` — كاميرا الخريطة متعددة الدقة، المسارات، الدبابيس، تنوير المحافظات.
- `reel_lib.py` — أدوات الرسم: الخطوط والنص الذهبي، الخيط والكرة، الخلفية، الحبيبات، الكاريوكي.
- `render_reel.py` — تجميع الفريم، الرندر المتوازي، ومكس الصوت (موسيقى بـ ducking + مؤثرات + loudnorm -14 LUFS).

## ملاحظات على الصوت
- الصوت الفعلي مختلف شوية عن `script.txt`: جملتي «ابقَ حتى النهاية... لأنك ستعرفُ أين تعيشُ قبيلتُك اليوم» و«اكتبها في التعليقات» **مش موجودين في الصوت**،
  و«وهل ذكرناها؟» **موجودة**. علشان كده التوقيت مأخوذ من الصوت نفسه (`inputs/words.json`) مش من `timings.json`.
- «اكتبها في التعليقات» ظاهرة على الشاشة بس مع أيقونة التعليق في الآخر.
